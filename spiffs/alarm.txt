# Alarm configuration file
# Format: minute hour day_of_month month day_of_week
# minute: 0-59 or */N for every N minutes
# hour: 0-23 or */N for every N hours, * for every hour
# day_of_month: 1-31, * (currently ignored, treated as *)
# month: 1-12, * (currently ignored, treated as *)
# day_of_week: 0-6 (0=Sunday, 1=Monday, ..., 6=Saturday), * for every day, 1-6 for Mon-Sat
#
# Examples:
# */5 * * * 1-6 = Every 5 minutes, Mon-Sat (not Sunday)
# 30 7 * * * = Every day at 7:30
# 0 8 * * 1-5 = Monday to Friday at 8:00
# 15 20 * * 0,6 = Sunday and Saturday at 20:15
#
# Debug alarm: Every 5 minutes except Sunday
*/5 * * * 1-6
0 7 * * 1-5
