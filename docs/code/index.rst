The source code
===============

One page per tracked C source under ``components/`` and ``main/``, with
a "Referenced from" index of the doc pages that link in. The pages
under ``gen/`` are generated by the ``mooncode`` extension at build
time (``builder-inited``, before the source scan) — do not edit them or
the ``gen/`` directory.

Roles
-----

The three roles the docs use to point into code:

- ``:cfile:`` — a whole file's source page, e.g.
  :cfile:`components/ui/screens.c`;
- ``:cfunc:`` — a function's section on that page, e.g.
  :cfunc:`moon_ui_screen_switched` (the screen-switch choke point,
  first definition wins if a name recurs);
- ``:clabel:`` — an exact line, e.g.
  :clabel:`components/ui/screens.c:534` — the
  ``create_screen_settings_hub`` definition (the hub ring geometry).

A target that no longer exists degrades to a plain non-linked literal
(rather than a broken link), so the build stays warning-free while
code moves; regenerate (or re-run the build) once the new sources are
in place.
